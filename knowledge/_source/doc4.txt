Today B tv 또는 2단 배너 등을 통해 고객이 진입한 후 이벤트 상세 내용을 확인하는 랜딩 구좌다.


2. 핵심 지표 정의
- UV: 해당 구좌를 이용한 순 이용자 수
- PV: 해당 구좌에서 발생한 이용량
- PV/UV: 이용자 1인당 평균 탐색량
- 매출: 해당 구좌를 통해 발생한 구매 매출
- UV당 매출: 매출 ÷ UV로 계산한 방문자당 매출 효율
- 구매전환율: 구매자 수 ÷ UV로 계산하며 구매자 데이터가 있을 때만 사용
- UV당 매출을 구매전환율이라고 표현하지 않는다.


3. 구좌별 성격 및 활용 기준
[Today B tv MASS]


구좌 성격:
- B tv 전고객을 대상으로 주요 콘텐츠와 프로모션을 노출하는 대표 진입 구좌다.
- 대규모 도달과 신작 인지도 확보에 적합하다.
- 콘텐츠 홍보와 프로모션 혜택을 함께 전달할 수 있다.


적합한 경우:
- 대중성이 높은 신작이나 주요 콘텐츠를 전고객에게 알리는 경우
- 단기간에 대규모 도달이 필요한 경우
- MASS 구매 프로모션이나 시즌 이벤트를 홍보하는 경우
- 콘텐츠의 관전 포인트와 혜택을 함께 전달해야 하는 경우


권장 카피 방향:
- 작품의 확인된 핵심 관전 포인트를 짧고 명확하게 전달한다.
- 혜택이 있으면 구매 조건, 혜택, 기간을 구분해 안내한다.
- 작품 정보와 혜택 정보를 한 문장에 과도하게 넣지 않는다.


권장 Userflow:
- Today B tv MASS → 콘텐츠 시놉시스 → 구매 또는 시청
- 상세 이벤트가 있는 경우: Today B tv MASS → 풀페이지 배너 → 구매 또는 참여


주의:
- 전고객 노출이 모든 콘텐츠에 효율적이라고 단정하지 않는다.
- 장르 선호층이 제한적인 콘텐츠는 TARGET 구좌와 비교해 검토한다.


[Today B tv TARGET]
구좌 성격:
- 특정 조건으로 추출된 고객을 대상으로 콘텐츠와 프로모션을 노출하는 맞춤형 진입 구좌다.
- 장르 선호도, 구매 이력, 이용 이력 등 타겟 적합도가 중요한 캠페인에 활용한다.


적합한 경우:
- 특정 장르 선호층이 뚜렷한 콘텐츠
- 유사 콘텐츠 구매·시청 고객을 대상으로 하는 캠페인
- 대규모 도달보다 고객 적합도와 효율이 중요한 경우
- 리텐션, 재구매, 가입 전환 등 특정 고객 행동을 유도하는 경우


권장 카피 방향:
- 타겟 고객이 관심을 가질 만한 확인된 콘텐츠 특징을 활용한다.
- 타겟 조건을 직접 노출하거나 고객이 감시받는다고 느낄 수 있는 표현은 사용하지 않는다.
- 혜택은 실제 대상 조건과 지급 조건이 확인된 범위에서 안내한다.


권장 Userflow:
- Today B tv TARGET → 콘텐츠 시놉시스 → 구매 또는 시청
- 상세 이벤트가 있는 경우: Today B tv TARGET → 풀페이지 배너 → 구매 또는 참여


주의:
- TARGET 캠페인은 타겟 조건, 모수, 배너 Capa, 쿠폰 Capa를 별도로 검증한다.
- 개인화 영역의 과거 평균을 현재 캠페인의 성과로 보장하지 않는다.


[2단 배너]


구좌 성격:
- 콘텐츠 또는 프로모션으로 고객의 진입을 유도하는 배너 구좌다.
- 핵심 메시지와 혜택을 비교적 간결하게 전달하는 데 적합하다.
- 단독 활용 또는 Today B tv를 보완하는 추가 노출 구좌로 활용할 수 있다.


관찰 인사이트:
- 분석 대상 기간에서 UV당 매출이 약 66원으로 관찰된 사례가 있다.
- 일부 분석에서 메인 MASS 구좌와 유사한 UV당 매출 효율을 보였다.
- 수치는 분석 기간, 표본 수, 콘텐츠 구성에 따라 달라질 수 있다.


적합한 경우:
- 구매 혜택이나 이벤트 메시지를 짧게 전달하는 경우
- Today B tv 외 추가 노출을 확보하는 경우
- 무료 콘텐츠, 단순 이벤트, 서브 프로모션을 안내하는 경우
- 풀페이지 배너로 고객을 진입시킬 시작 구좌가 필요한 경우


권장 카피 방향:
- 고객이 한 번에 이해할 수 있는 하나의 핵심 메시지를 사용한다.
- 상품명, 구매 조건, 핵심 혜택, 기간 중 중요한 정보만 선택한다.
- 복잡한 경품 조건과 유의사항은 풀페이지 배너에서 안내한다.


권장 Userflow:
- 2단 배너 → 콘텐츠 시놉시스 → 구매 또는 시청
- 상세 이벤트가 있는 경우: 2단 배너 → 풀페이지 배너 → 구매 또는 참여


주의:
- 트래픽 규모가 작을 수 있으므로 핵심 노출 구좌를 완전히 대체한다고 단정하지 않는다.
- Today B tv와 동시에 사용할 경우 같은 카피를 반복하지 않고 역할을 구분한다.


[롱배너]


구좌 성격:
- 콘텐츠 블록보다 큰 사이즈로 노출되는 콘텐츠 홍보형 구좌다.
- 영화, 방송, 시리즈 등 특정 콘텐츠의 인지도와 관심을 높이는 용도로 주로 사용한다.
- 콘텐츠의 키아트, 타이틀, 주요 관전 포인트를 시각적으로 강조하는 데 적합하다.
- 일반적으로 콘텐츠 시놉시스 화면으로 고객의 진입을 유도한다.


적합한 경우:
- 신작이나 주요 콘텐츠를 크게 노출해야 하는 경우
- 콘텐츠 키아트와 타이틀을 중심으로 관심을 유도하는 경우
- Today B tv 외 영역에서 콘텐츠 홍보 노출을 추가로 확보하는 경우
- 할인이나 경품보다 작품 자체의 매력을 우선 전달하는 경우


권장 카피 방향:
- 작품의 확인된 핵심 관전 포인트를 짧고 직관적으로 전달한다.
- 확인된 인물, 상황, 장르, 관계 등 콘텐츠 고유 특징을 활용한다.
- 타이틀과 키아트를 방해할 정도로 긴 문구를 사용하지 않는다.
- 혜택이 있더라도 콘텐츠 홍보가 주목적이면 혜택 문구는 보조적으로 사용한다.


권장 Userflow:
- 롱배너 → 콘텐츠 시놉시스 → 구매 또는 시청
- 상세 이벤트 안내가 필요한 경우에만 롱배너 → 풀페이지 배너 → 구매 또는 참여 구조를 검토한다.


주의:
- 롱배너를 경품, 지급 조건, 유의사항을 상세히 설명하는 구좌로 사용하지 않는다.
- 작품 정보가 확인되지 않았다면 제목만 보고 줄거리나 장르를 만들지 않는다.
- 2단 배너와 함께 사용할 경우 동일한 카피를 반복하지 않는다.


[오핫콘 — 오늘 핫한 콘텐츠]


영역 성격:
- 별도의 배너 이미지나 배너 카피를 제작하지 않는 콘텐츠 노출 영역이다.
- 고객이 콘텐츠를 선택하면 해당 콘텐츠의 시놉시스 화면으로 바로 연결된다.
- 신작을 빠르게 알리거나 작품성이 좋고 추천할 가치가 있는 콘텐츠를 안내하는 데 적합하다.
- 프로모션 혜택 설명보다 콘텐츠 타이틀과 작품 자체의 매력을 전달하는 역할이 중심이다.


관찰 인사이트:
- 탐색 깊이는 비교적 짧지만 구매 매출이 높게 나타난 사례가 있다.
- 타이틀 인지도, 신작성, 화제성, 추천 필요성이 고객 선택에 영향을 줄 가능성이 있다.
- 오핫콘 단독 수치가 확인되지 않은 경우 다른 영역과 합산된 수치를 사용하지 않는다.


적합한 경우:
- 신규 공개 또는 신규 구매가 시작된 콘텐츠
- 고객에게 적극적으로 소개할 필요가 있는 주요 콘텐츠
- 작품성, 화제성, 시의성 등 추천 근거가 있는 콘텐츠
- 타이틀과 포스터만으로 고객의 관심을 유도할 수 있는 콘텐츠
- 시놉시스 진입을 통해 상세 정보와 구매·시청을 유도하는 경우


운영 방향:
- 별도의 배너 카피와 프로모션 배너 에셋을 생성하지 않는다.
- 콘텐츠 타이틀, 포스터, 편성 순서 등으로 고객의 관심을 유도한다.
- 혜택과 이벤트 조건은 오핫콘이 아닌 시놉시스 화면에서 안내한다.


권장 Userflow:
- 오핫콘 노출 → 콘텐츠 선택 → 시놉시스 → 구매 또는 시청


에셋 및 JSON 처리:
- 오핫콘은 별도 제작 배너가 아니므로 assets 배열에 오핫콘 객체를 생성하지 않는다.
- 오핫콘에 대응하는 임의의 배너 타입이나 이미지 URL을 만들지 않는다.
- Mermaid에는 콘텐츠 진입 경로를 설명하는 일반 노드로 표시할 수 있다.
- Userflow와 assets의 1:1 매칭 검증에서 오핫콘은 배너 에셋 대상에서 제외한다.


주의:
- 오핫콘용 2단 배너 카피나 별도 이미지 URL을 생성하지 않는다.
- 확인되지 않은 작품성, 인기, 화제성을 사실처럼 표현하지 않는다.
- 경품, 지급 조건, 유의사항 등 복잡한 이벤트 내용을 오핫콘에서 설명하지 않는다.


[풀페이지 배너]

- 별도의 이벤트 참여나 상세 안내가 필요하지 않은 경우

카피 및 정보 구성:

- 참여 또는 구매 조건
- 혜택 지급 방식과 지급 시점

주의:
- 풀페이지를 Today B tv, 2단 배너와 같은 최초 노출 구좌로 분류하지 않는다.
- 풀페이지 사용 여부는 혜택의 복잡도와 상세 안내 필요성을 기준으로 결정한다.
- 확인되지 않은 지급 조건과 유의사항을 임의로 만들지 않는다.


4. 목적별 추천 조합


[전고객 대상 신작 홍보]

- 오핫콘으로 신작을 안내하고 시놉시스 진입을 유도한다.


[특정 고객 대상 콘텐츠 홍보]
우선 검토:
- Today B tv TARGET
- 롱배너


활용 방향:
- 관심 가능성이 높은 고객에게 콘텐츠를 노출한다.
- 작품 자체의 매력과 확인된 관전 포인트를 중심으로 안내한다.


[단순 구매 혜택 프로모션]

적용 기준:

- 별도의 이벤트 참여와 상세 유의사항 안내가 필요하지 않은 경우

- 2단 배너
- 풀페이지 배너


권장 흐름:

적용 기준:
- 경품, 추첨, 복수 혜택, 참여 조건, 지급 일정 등 상세 설명이 필요한 경우


5. 구좌별 카피 역할


- Today B tv MASS: 작품의 핵심 관전 포인트와 주요 혜택을 전고객에게 명확하게 전달한다.
- Today B tv TARGET: 타겟 고객이 관심을 가질 확인된 콘텐츠 특징과 혜택을 전달한다.
- 2단 배너: 하나의 핵심 프로모션 메시지와 진입 행동을 짧게 전달한다.
- 롱배너: 콘텐츠의 키아트, 타이틀, 핵심 관전 포인트를 중심으로 홍보한다.
- 오핫콘: 별도 카피를 제작하지 않고 타이틀과 포스터를 통해 콘텐츠를 안내한다.
- 풀페이지 배너: 경품, 참여 조건, 지급 방식, 유의사항 등 상세 정보를 제공한다.


6. Userflow 및 에셋 처리 원칙


- Today B tv, 2단 배너, 롱배너, 풀페이지 배너는 실제 사용 시 Userflow 노드와 assets를 1:1로 연결한다.
- 오핫콘은 별도 배너 에셋이 아니므로 assets 1:1 매칭 대상에서 제외한다.
- 풀페이지는 진입 구좌 없이 단독으로 시작하는 Userflow를 만들지 않는다.
- 상세 이벤트가 없는 경우 풀페이지를 불필요하게 추가하지 않는다.
- UI 템플릿 이미지와 실제 캠페인 소재 URL을 구분한다.
- 존재하지 않는 배너 타입이나 이미지 URL을 임의로 만들지 않는다.
