# 빅배너 / 월정액 가입 빅배너

JSON `type`: `BIG_BANNER` · 규격: [banner-specs.md](banner-specs.md)

## 이게 뭔가?

특정 GNB의 **최상단에만** 편성할 수 있는, 좌 텍스트 / 우 이미지 구성 배너.
용도가 다른 두 가지 변형이 있다.

## 왜 존재하나?

GNB 최상단은 해당 카테고리 진입 고객이 반드시 지나치는 자리다.
장르 타겟 캠페인의 **1차 진입 구좌**로 강력하다.

## 언제 쓰나?

- 영화/애니/방송 등 **장르 GNB 단위 캠페인**
- 월정액 미가입자에게 가입을 직접 유도할 때 (월정액 가입 빅배너)

---

## 변형 1 — 빅배너 (홈)

| 항목 | 값 |
|---|---|
| 편성 영역 | 홈 |
| sw_version | **5.3.0 ~ 5.4.0** (상한 있음) |
| 장점 | UI 530~540에서 홈 최상단 메인 노출 |

## 변형 2 — 빅배너 (장르 GNB)

| 항목 | 값 |
|---|---|
| 편성 영역 | 영화 / 애니 / 방송 |
| sw_version | 5.3.0 이상 |
| 장점 | 영화·TV 다시보기·애니 GNB 최상단 편성 가능 |

## 변형 3 — 월정액 가입 빅배너

| 항목 | 값 |
|---|---|
| 편성 영역 | Btv+, 지상파3사, CJ ENM, JTBC, MBN, TV조선 |
| 노출 대상 | 해당 월정액 **미가입자** |
| 위치 | 월정액별 GNB의 '가입하기' 버튼 위 |
| sw_version | 5.4.1 이상 |
| 랜딩 | **바로가기 없음** — 구매창 직행 |

**장점**: 가입하기 버튼에 표시되는 **쿠폰 반영 최저가 가격**을 활용해
직접적인 가격 소구가 가능하다.

**단점**: 별도 랜딩 없이 구매창으로 이동해 **전달할 수 있는 정보가 적다.**
복잡한 혜택 구조에는 부적합하다.

---

## 카피 방향

- 로고 + 텍스트 2줄, 줄당 19자 제한 → **한 문장에 하나의 메시지**
- 월정액 가입 빅배너는 **가격·할인율 소구**가 가장 효과적이다
- 장르 GNB 빅배너는 해당 장르 선호 고객이 보므로 **작품·라인업 소구**를 우선한다

## 권장 Userflow

```
빅배너 (장르 GNB) → 콘텐츠 시놉시스 → 구매 또는 시청
월정액 가입 빅배너 → 구매창 (직행)
```
