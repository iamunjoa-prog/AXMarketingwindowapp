# 풀페이지(풀프로모션) 배너

JSON `type`: `FULL_PROMO_BANNER` · 규격: [banner-specs.md](banner-specs.md)

## 이게 뭔가?

B tv 화면 **전면(100% 영역)** 을 활용하는 배너.
배경 1개 + 카드 배너 3개를 **세트로 구성**해야 한다.

## 왜 존재하나?

경품·참여 방법·지급 조건·유의사항처럼 **설명할 내용이 많은 프로모션**을
한 화면에서 전부 전달하기 위해서다.

## 언제 쓰나?

> 🚨 **풀페이지는 최초 노출 구좌가 아니다.**
> Today B tv 또는 2단 배너 등을 클릭한 고객이 진입하는 **2차 Depth 랜딩**이다.
> 진입 구좌 없이 단독으로 시작하는 Userflow를 만들지 않는다.

### 쓴다

- 경품 종류와 당첨 조건을 상세히 안내하는 이벤트
- 혜택이 여러 개이거나 고객별 조건이 다른 프로모션
- 참여 방법·지급 시점·당첨자 발표일·유의사항 안내가 필요한 경우
- 진입 배너 카피만으로 내용을 충분히 설명하기 어려운 경우
- 중요도 높은 시즈널 프로모션, 월정액 MASS 프로모션

### 안 쓴다

- 단순 할인·포인트백처럼 조건과 혜택이 간단한 경우
- [시놉시스 배너](synopsis-banner.md)만으로 조건·혜택·기간을 명확히 전달 가능한 경우
- 별도 이벤트 참여나 상세 안내가 필요하지 않은 경우

---

## 장단점

**장점**
1. 백그라운드 전면을 활용해 프로모션 이미지를 강조할 수 있다
2. 배경 내 3~4줄 + 각 배너 내 1~2줄로 내용 기재 가능
3. 배너와 배경을 조합해 다양한 디자인이 가능하다

**단점**
**상하 편성 블록이 아예 보이지 않는다.** 다른 콘텐츠 노출을 완전히 가린다.

---

## 관찰 인사이트

- 분석 대상 기간에서 **UV당 매출 약 875원**으로 높게 관찰된 사례가 있다.
- 단, 풀페이지 방문자는 **진입 배너를 이미 클릭한 관심 고객**이므로
  **선택 편향이 포함**된다.
- 높은 UV당 매출을 풀페이지 자체의 인과적 전환 효과로 단정하지 않는다.
- 성과는 Today B tv·2단 배너 등 **진입 구좌와 랜딩 경로를 함께 고려**해 해석한다.

→ [domain/performance-benchmarks.md](../domain/performance-benchmarks.md)

## 카피 및 정보 구성

다음 순서로 구성한다.

1. 이벤트명과 핵심 혜택
2. 참여 또는 구매 조건
3. 혜택 지급 방식과 지급 시점
4. 이벤트 기간
5. 당첨자 발표일과 경품 지급일
6. 유의사항과 제외 조건
7. 구매 또는 참여 CTA

## 권장 Userflow

```
Today B tv 또는 2단 배너 → 풀페이지 배너 → 구매 또는 이벤트 참여
```

상세 설명이 필요 없다면:
```
Today B tv 또는 2단 배너 → 시놉시스 → 구매
```

## 주의

- 풀페이지를 Today B tv·2단 배너와 같은 **최초 노출 구좌로 분류하지 않는다.**
- 사용 여부는 **혜택의 복잡도와 상세 안내 필요성**을 기준으로 결정한다.
- **확인되지 않은 지급 조건·유의사항을 임의로 만들지 않는다.**
