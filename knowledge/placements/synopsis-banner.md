# 시놉시스 배너

JSON `type`: `SYNOPSIS_BANNER` · 규격: [banner-specs.md](banner-specs.md)

## 이게 뭔가?

특정 콘텐츠의 **시놉시스(상세) 화면 내에 편성하는 배너**.
고객의 최종 구매 결정 직전에 노출된다.

## 왜 존재하나?

시놉시스 화면은 **구매 버튼 바로 옆**이다. 여기서 조건·혜택·기한을
명확히 전달하면 전환율이 크게 오른다.

## 언제 쓰나?

- 특정 타이틀과 연관된 이벤트를 하는 경우
- 구매 조건과 혜택을 최종 확인시켜야 하는 경우

---

## 특성

**장점**
1. 타이틀 연관 이벤트에 최적
2. **복수 타이틀에 동일한 시놉배너 편성 가능**
3. 타이틀에 시놉배너 편성 시, Today B tv에 해당 타이틀이 노출되면
   **시놉배너가 함께 노출됨** (MASS 편성 5.4.3 이상, Target 편성 5.5.1 이상)

**단점**
영역이 작다. 최대 2줄, 8자 제한.

**랜딩 특이사항**
`쿠폰받기` 랜딩은 **UI 5.4.2 이상**에서만 동작한다.

---

## 작성 기준

- 조건·혜택·기한을 **확인된 정보 범위에서** 명확하게 작성한다
- 할인쿠폰 / 포인트백 / 경품 / 자동 지급 / 후지급 등 **지급 방식을 구분**한다
- `100% 지급`, `전원 증정`, `즉시 지급`, `단독`은 **실제 조건이 확인된 경우에만** 사용한다
- **구매 조건과 감상·시청 완료 조건을 혼용하지 않는다**
- 사용자가 제공하지 않은 금액·날짜·지급 시점을 만들지 않는다
- 혜택 지급 시점이 미확정이면 확정 표현을 쓰지 않는다

## 작성 구조

세 가지 중 하나를 택한다.

- 구매 조건 + 혜택
- 구매 조건 + 혜택 + 기한
- 행동 유도 + 확인된 혜택

## 작성 형식

```
(구매 조건) 시 (혜택)
(확인된 혜택), (종료일)까지
지금 (구매 행동)하고 (확인된 혜택) 받기
```

괄호 안의 값은 **현재 캠페인에서 확정된 정보로 교체**한다.
템플릿 문자열을 그대로 출력하지 않는다.
