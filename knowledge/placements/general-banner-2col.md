# 2단 배너

JSON `type`: `GENERAL_BANNER` · 규격: [banner-specs.md](banner-specs.md)

## 이게 뭔가?

B tv의 **가장 기본적인 배너**. 콘텐츠 블록 앞/뒤에 편성하거나
여러 개를 모아 이벤트블록으로 구성할 수 있다.
좌 프리뷰 / 우 프리뷰 / 배너의 3단 구성이다.

## 왜 존재하나?

구성 자유도가 높고 **커버하는 UI가 가장 넓다**(`sw_version: ALL`).
Today B tv를 보완하는 추가 노출을 확보하는 데 가장 안전한 선택지다.

## 언제 쓰나?

- 구매 혜택이나 이벤트 메시지를 짧게 전달하는 경우
- Today B tv 외 추가 노출을 확보하는 경우
- 무료 콘텐츠, 단순 이벤트, 서브 프로모션 안내
- 풀페이지 배너로 진입시킬 시작 구좌가 필요한 경우

---

## 장점

1. 콘텐츠와 함께 노출되어 **콘텐츠 연관 마케팅**에 좋다
2. 1~3단 배너로 이벤트블록을 자유롭게 구성 가능 (디자인도 자유)
3. 각 GNB 상단 콘텐츠 블록에 노출 시 **편성 위치를 유리하게 할당**받을 수 있다
4. 3단 구성이라 이벤트를 설명할 영역이 많다
5. 대부분의 UI에서 작동해 커버리지가 넓다

## 단점

가장 평이한 스타일이라 가이드대로만 디자인하면 **주목도가 낮다.**

---

## 관찰 인사이트

- 분석 대상 기간에서 **UV당 매출 약 66원**으로 관찰된 사례가 있다.
- 일부 분석에서 메인 MASS 구좌와 유사한 UV당 매출 효율을 보였다.
- 수치는 분석 기간·표본 수·콘텐츠 구성에 따라 달라질 수 있다.

→ [domain/performance-benchmarks.md](../domain/performance-benchmarks.md)

## 카피 방향

- 고객이 **한 번에 이해할 수 있는 하나의 핵심 메시지**만 사용한다
- 상품명, 구매 조건, 핵심 혜택, 기간 중 **중요한 것만 선택**한다
- 한 배너에 작품 설명·혜택·지급 조건·유의사항을 모두 넣지 않는다
- 복잡한 경품 조건과 유의사항은 [풀페이지 배너](full-promo-banner.md)에서 안내한다
- Today B tv와 동시 사용 시 **같은 카피를 반복하지 않고 역할을 구분**한다

## 권장 Userflow

```
2단 배너 → 콘텐츠 시놉시스 → 구매 또는 시청
2단 배너 → 풀페이지 배너 → 구매 또는 참여   (상세 이벤트가 있는 경우)
```

## 주의

트래픽 규모가 작을 수 있으므로 **핵심 노출 구좌를 완전히 대체한다고 단정하지 않는다.**
