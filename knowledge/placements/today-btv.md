# Today B tv (MASS / TARGET)

JSON `type`: `TODAY_BTV` · 규격: [banner-specs.md](banner-specs.md)

## 이게 뭔가?

B tv 첫 화면의 80% 이상을 차지하는 **메인 배너**. MASS(전고객)와
TARGET(조건 추출) 두 가지 편성 방식이 있다.

## 왜 존재하나?

TV를 켜자마자 첫 화면에 노출되어 **효율이 가장 높다.**
중요한 이벤트라면 1순위로 제작한다.

## 언제 쓰나?

대규모 도달이 필요하거나, 캠페인의 대표 진입 구좌가 필요할 때.

---

## Today B tv MASS

**성격**: B tv 전고객 대상 대표 진입 구좌. 대규모 도달과 신작 인지도 확보에 적합.
콘텐츠 홍보와 프로모션 혜택을 함께 전달할 수 있다.

**적합한 경우**
- 대중성이 높은 신작·주요 콘텐츠를 전고객에게 알리는 경우
- 단기간 대규모 도달이 필요한 경우
- MASS 구매 프로모션이나 시즌 이벤트 홍보
- 콘텐츠 관전 포인트와 혜택을 함께 전달해야 하는 경우

**주의**
- 전고객 노출이 모든 콘텐츠에 효율적이라고 단정하지 않는다.
- 장르 선호층이 제한적인 콘텐츠는 TARGET과 비교 검토한다.

## Today B tv TARGET

**성격**: 특정 조건으로 추출된 고객 대상 맞춤형 진입 구좌.
장르 선호도, 구매 이력, 이용 이력 등 타겟 적합도가 중요한 캠페인에 활용.

**적합한 경우**
- 특정 장르 선호층이 뚜렷한 콘텐츠
- 유사 콘텐츠 구매·시청 고객 대상 캠페인
- 대규모 도달보다 고객 적합도·효율이 중요한 경우
- 리텐션, 재구매, 가입 전환 등 특정 행동 유도

**주의**
- TARGET 캠페인은 **타겟 조건, 모수, 배너 Capa, 쿠폰 Capa를 별도 검증**한다.
- 개인화 영역의 과거 평균을 현재 성과로 보장하지 않는다.
- 타겟 조건을 카피에 직접 노출하지 않는다. → [domain/targeting.md](../domain/targeting.md#카피-작성-시-주의)

---

## 카피 방향

- **후킹 카피**: 작품의 확인된 감정·관계·상황·관전 포인트를 활용
- **혜택 카피**: 구매 조건·혜택·기한을 짧고 명확하게
- 후킹과 혜택 설명이 **같은 내용을 반복하지 않도록 역할을 분리**한다
- 작품 정보보다 혜택만 과도하게 강조하지 않는다
- 작품 정보와 혜택 정보를 한 문장에 과도하게 넣지 않는다

## 권장 Userflow

```
Today B tv (MASS/TARGET) → 콘텐츠 시놉시스 → 구매 또는 시청
Today B tv (MASS/TARGET) → 풀페이지 배너 → 구매 또는 참여   (상세 이벤트가 있는 경우)
```

## 제작 리스크

UI 541 / 542 / 561 이상이 서로 달라 **버전별 별도 이미지 제작이 필요**하고,
제작 가이드가 엄격해 소요 기간이 길다. 일정 산정 시 반영한다.
